# Express Server

This project is an Express.js server for the HMS-Backend.

## Features

- RESTful API endpoints
- Modular route handling
- Middleware support

## Requirements

- Node.js (v18+ recommended)
- npm

## Getting Started

1. **Install dependencies:**
    ```bash
    npm install
    ```

2. **Start the server:**
    ```bash
    npm start
    ```

3. **Development mode (with auto-reload):**
    ```bash
    npm run dev
    ```

## Project Structure

```
express server/

```
